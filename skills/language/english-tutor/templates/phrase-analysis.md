# 片語分析版型

適用於使用者詢問片語、慣用語、片語動詞、介系詞片語、固定搭配，或完整句中的局部英文結構。

依問題複雜度選用必要區段。片語分析的重點是先理解「整體如何表達意思」，再拆解內部結構；不要因為片語包含多個單字，就逐字分開解釋而失去整體語意。

## 1. 整體意思

先給出符合原句語境的自然繁體中文意思。

若片語具有非字面義、慣用義或領域特定義，優先解釋整體意思，再視需要說明字面意思。

例如：

`take the application down`

在 Software / Operations 語境中通常表示：

> 讓應用程式停止服務／使應用程式停機

而不是字面上的：

> 把應用程式拿下來

## 2. 基本結構

拆解片語內真正影響理解的成分。

可能包括：

- 核心動詞
- 名詞
- 受詞
- 介系詞
- particle
- `V-ing`
- infinitive
- modifier
- complement
- 固定搭配

例如：

`without taking the application down`

可以先拆成：

`without + V-ing`

其中：

- `without` → 介系詞
- `taking` → `take` 的 `V-ing` 形式
- `the application` → `take` 的受詞
- `down` → 與 `take` 形成 `take ... down`

必要時再分析：

`take + O + down`

不要因為看到 `V-ing` 就直接判定為 gerund 或 participle；應依它在目前結構中的功能判斷。

## 3. 片語類型

只有在有助於理解時標示片語類型，例如：

- phrasal verb
- prepositional phrase
- idiom
- collocation
- fixed expression
- `V-ing` construction
- infinitive construction

不要為了分類而分類。

若不同文法框架可能有不同分析，採用適合學習者且前後一致的分析方式，必要時指出存在其他合理分析。

## 4. 在原句中的功能

若使用者提供完整句子，說明這個片語在原句中：

- 修飾什麼
- 補充什麼
- 描述什麼
- 與哪個動詞或名詞形成關係
- 是否作為某個句子成分的一部分

必要時同時區分：

- 句法形式
- 句子功能
- 語意功能

不要僅依中文翻譯決定文法角色。

## 5. 為什麼這樣用

解釋真正值得學習的結構關係，例如：

- 為什麼使用這個介系詞
- 為什麼後面接 `V-ing`
- particle 為什麼放在這個位置
- 受詞可以放在哪裡
- 某個搭配為什麼不能逐字理解
- 替換某個成分後意思如何改變

例如：

`without + V-ing`

表示：

> 在不做某件事的情況下

因此：

`without taking the application down`

可以理解為：

> 在不讓應用程式停機的情況下

## 6. 語境與語氣

只在有實際差異時說明：

- 日常／正式
- 口語／書面
- 慣用程度
- 專業領域含義
- register
- 常見 collocation

Technical English 只是可能的 context，不是固定必備內容。

## 7. 易混淆表達

只有在存在實際學習風險時加入。

比較：

- 結構差異
- 語意差異
- 使用情境
- 是否可以互換

不要只列出中文意思相近的表達。

## 8. 常見例句

提供少量、自然且能呈現相同用法的例句。

優先使用不同語境，避免只替換名詞。

| 例句 | 中文意思 |
| --- | --- |
| ... | ... |

## 9. 記憶方式

只有在片語具有值得泛化的規則時提供。

例如：

`without + V-ing`
→ 不做……／在沒有……的情況下

`take + O + down`
→ 使 O 停止運作、移除 O，實際意思依語境決定

不要把只適用於單一例句的解釋包裝成通用公式。

## 分析限制

- 優先理解完整片語，再分析單字；不要先逐字翻譯再拼湊意思。
- phrasal verb 必須把動詞與 particle 視為整體分析，不能只用 particle 的字面意思解釋。
- phrasal verb 若涉及受詞位置，應確認是否可分離（separable）以及代名詞受詞的位置限制。
- 同一動詞片語可能具有多個意思，必須依目前上下文選擇，不要一次傾倒所有字典義。
- 介系詞片語應先判斷其組成與附著對象，再說明語意功能。
- `V-ing` 是形式，不代表固定的文法功能；應依所在結構判斷。
- idiom、fixed expression、collocation、phrasal verb 不應因表面相似而混為同一類。
- 若片語其實是較大的可重用句型，簡要說明後可轉由 `pattern-analysis.md` 深入分析。
- 若理解片語必須依賴完整句子的主要子句或句子骨架，應轉由 `sentence-analysis.md` 補充，而不是在片語模板中重建整句分析。
