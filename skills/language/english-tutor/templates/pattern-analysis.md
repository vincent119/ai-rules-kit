# 句型分析版型

適用於使用者詢問句型本身，或需要從原句抽取可重用、可遷移規則的問題。

依問題複雜度選用下列區塊；不要為了湊齊結構而逐項輸出。優先回答使用者真正詢問的文法關係，再視需要補充比較、例句與記憶方式。

1. **核心意思**：先說明此句型在目前語境要表達的核心關係。
2. **基本結構**：列出句法公式，例如 `keep + O + V-ing`，並標示主要成分。必要時同時標示「句法形式」與「句子功能」，例如 `multiple instances = NP / O`、`as a POST request = PP / 說明 O 的傳送形式`。
3. **原始例句**：保留原句，必要時以括號、分段或表格將原句成分對應到句型公式。
4. **為什麼這樣用**：分開說明句法形式與語意功能。句法形式回答「它由什麼組成、位於哪裡、附著在哪裡」；語意功能回答「它在此語境表達什麼角色、用途、狀態、結果或關係」。
5. **常見例句**：提供少量能呈現相同核心結構的自然例句；避免只替換名詞而產生高度重複的例句。
6. **易混淆結構**：比較外觀相近但受詞關係、修飾範圍、句法角色或語意不同的結構。應說明「哪裡不同」以及「為什麼意思會改變」，不要只判斷對錯。
7. **常見錯誤**：指出會改變句法關係或意思的典型誤用。若另一種寫法本身文法成立但意思不同，應標示為「結構／語意不同」，不可誤判為文法錯誤；沒有明顯風險時省略。
8. **同類句型**：列出具有相似語意關係或結構表面的相關句型，並指出共同點與必要差異；不得因表面皆為 `V + O + as + X` 就宣稱其句法行為完全相同。
9. **語境延伸**：說明正式度、自然度、領域語境或常見搭配；只保留與理解目前句型有關的資訊。Technical English 只是可能的 context，不是固定必備內容。
10. **相近句型**：對照語意接近但句法不同的替代說法，說明何時可以互換、何時不能互換，以及替換後焦點或語氣是否改變。
11. **記憶公式**：用精簡公式保留可泛化、可遷移到其他句子的規則。記憶公式是學習輔助，不得取代精確的句法分析。
12. **一句話記憶**：以一句繁體中文概括最值得記住的用法。

## 成分標示原則

分析句型時，應區分「句法形式」與「句子功能」。

常見句子功能：

- `S`：Subject
- `V`：Verb
- `O`：Object
- `C`：Subject Complement
- `OC`：Object Complement
- `IO`：Indirect Object
- `DO`：Direct Object

常見句法形式：

- `NP`：Noun Phrase
- `VP`：Verb Phrase
- `PP`：Prepositional Phrase
- `AdjP`：Adjective Phrase
- `AdvP`：Adverb Phrase
- `Clause`：子句

同一段文字可以同時具有句法形式與句子功能。

例如：

`multiple instances`

可以分析為：

- 句法形式：`NP`
- 句子功能：`O`

因此可簡寫為：

`multiple instances = NP / O`

不要把 `NP`、`PP` 等句法形式與 `O`、`C`、`OC` 等句子功能當成同一層級的標籤。

## 分析限制

- 不要把語意上的「角色、用途、身分、形式、結果」直接當成句法上的補語標籤。
- `as + NP` 在本 Skill 中預設以介系詞片語（PP）分析；若特定結構存在其他合理分析，應指出採用的分析方式。
- 在 `use + O + as + NP`、`send + O + as + NP` 等結構中，`as + NP` 通常說明 O 的用途、形式、角色或身分；不可僅因語意上描述 O 就一律標為 `OC`。
- 是否能在特定文法理論中把某成分進一步分析為 complement，應依動詞、句法測試與採用的分析框架判定，不可由中文翻譯直接推導。
- 結構標示應先回答「它由什麼組成、附著在哪裡」，再回答「它在此語境表達什麼意思」。
- `V-ing`、`to + V`、`as + NP` 等只是表面形式；必須依它們在實際句子中的功能判斷，不可只看到形式就固定套用一種文法角色。
- 不要因為兩個句子意思不同，就把其中一個判定為文法錯誤。先判斷句法是否合法，再比較句法角色與語意。
- 存在多種合理句法分析時，優先採用適合學習者理解且前後一致的分析方式；必要時指出其他合理分析，不要把有爭議的分析寫成唯一答案。
