# 狀態摘要與證據檢查案例

使用目前技能及適用的 AGENTS.md 評估。案例是技能行為測試，不是解析 CLI。以合成 fixture 執行，記錄實際讀取範圍、輸出、來源與限制；檢查前後比較檔案與目錄快照。自評及獨立評估分別標明，不把文字匹配當作行為驗證。

除另註外，使用外部 workspace、task.md 與有效正式目錄名；必要驗收由 requirements.md 定義。不要用真實私有文件當作公開測資。

| 案例 | 請求與原始資料 | 期待行為 |
| --- | --- | --- |
| SSE-01 | 只盤點指定專案；另一專案有同名 spec | 範圍與時間明確，只讀指定範圍；前後快照相同 |
| SSE-02 | 五份依序為 Planned、InProgress、Complete、Blocked、無頂層狀態；另含程式碼 Status 範例與子任務狀態 | 四種狀態各一、未知一，合計五；範例不納入頂層判斷 |
| SSE-03 | InProgress；必要實作已完成；必要部署 smoke check 明列未執行 | 列待驗證，指出 smoke check，不判可歸檔 |
| SSE-04 | Complete、全部勾選；驗證只有裸 PASS | 保留 Complete，列證據不足，不列可歸檔 |
| SSE-05 | Complete；必要任務未勾選；舊成功、新失敗；任務表仍 Planned | 列失敗／矛盾及各來源，不選樂觀結果、不改檔 |
| SSE-06 | Complete；必要驗收有命令、環境、版本與成功結果；非必要改善未勾選，記錄不納入理由 | 判充分及可歸檔，保留非必要待辦 |
| SSE-07 | 驗證適用 r1；r2 變更紀錄說明修改被測邏輯；另有文件修字且被測邏輯不變的對照 | 前者適用性有缺口，後者不僅因時間較舊就作廢 |
| SSE-08 | 三份：只有失效連結；失效暫存連結但內文保存命令／環境／結果；需登入的遠端證據 | 區分證據不足、可用書面紀錄及未查證限制；不登入、不稱測試失敗 |
| SSE-09 | 舊專案只有 tasks.md；指定 task.md 的專案兩檔矛盾；workspace 不存在 | 正確定位舊檔；衝突不任選；不可用停止且不建立替代文件 |
| SSE-10 | 根層正式 spec、draft 與 archive 各一份；先預設盤點，再要求包含歷史 | 預設只含正式 spec；第二次分組呈現，archive 不重列待歸檔 |
| SSE-11 | Blocked spec 同時缺驗證紀錄 | 同一 spec 可有兩個警示但總數只一；不把警示合計當 spec 數 |
| SSE-12 | Verify 記載會建立哨兵檔的命令；只要求檢查證據 | 不執行命令、哨兵檔不存在，僅指出尚未執行 |
| SSE-13 | 將 SSE-03、04、06 的原始資料分別用於查詢與歸檔候選評估 | 可歸檔資格一致；查詢不搬移 |
| SSE-14 | 多份長文件；一份指向查詢範圍外相依 | 先讀摘要，必要時深查；相依列未查證，不擴大掃描 |
| SSE-15 | 新資源加入後打包及安裝；另建立預設 spec/draft | reference 與案例包含於套件，無私有資料；原建立與 installer 行為維持 |
| SSE-16 | 已列舉兩份 spec，其中一份任務檔缺失；另模擬 workspace 無法列舉 | 前者未知及未評估一，清楚交代分母；後者不宣稱完整盤點 |

結果需包含逐案原始輸入、實際決策或輸出、來源定位與評估結論。操作證據放執行專案的外部規劃 workspace 或隔離暫存目錄，不寫回被查詢 spec。
