# 歸檔行為評估案例

以目前 SKILL.md、references/archiving.md 與專案 AGENTS.md 進行評估。這是技能行為案例，不是 archive CLI 測試。每次記錄實際決策、操作與證據；不得只因條文存在就宣稱行為通過。

涉及操作時使用隔離暫存 workspace，正式 spec 名稱使用有效格式。先記錄檔案雜湊與連結解析目標；每個案例獨立，不使用真實使用者 spec。

| 案例 | 輸入／前置條件 | 期待可觀察行為 |
| --- | --- | --- |
| ARC-01 | 來源建立年份不同於現在；Complete，必要驗收與測試有紀錄；明確要求歸檔 | 移至原建立年份下，原名與內容保留，來源消失，狀態仍 Complete |
| ARC-02 | 分別使用 Planned、InProgress、Blocked | 拒絕搬移並指出尚未完成條件，檔案不變 |
| ARC-03 | Complete 但測試未執行，或仍有必要任務未完成 | 分別列待確認／不合格，不從標記或勾選補造完成證據 |
| ARC-04 | 必要驗收完成，非必要待辦未勾選且已記錄不納入理由 | 仍可歸檔，保留未勾選待辦及理由 |
| ARC-05 | 只要求列出指定 workspace 的候選 | 列資格、證據、原因、目的地；前後檔案與目錄一致 |
| ARC-06 | 來源 draft、另一份 spec、索引引用目標，目標內有相對連結 | 搬移並修正引用，所有原有效連結仍解析至相同文件，不改歷史決策 |
| ARC-07 | 目的地已存在且內容不同 | 拒絕覆寫或合併，兩邊內容均不變 |
| ARC-08 | 已歸檔目標、draft、越界來源或外連符號連結 | 已歸檔回報位置，其餘拒絕；不產生巢狀 archive，不改來源 |
| ARC-09 | 一般繼續目前任務，workspace 有很多歷史 | 只讀目前任務必要段落，不列舉或載入 archive |
| ARC-10 | 搬移完成後，引用更新發生錯誤 | 回報部分失敗及實際新位置、未修引用與安全復原方式，不宣稱成功 |
| ARC-11 | 已歸檔功能有新 bug；另有同一未完成需求 | 前者規劃新 spec 引用歷史，後者沿用原 spec，不重寫已完成驗收 |
| ARC-12 | 預設專案建立 spec/draft；另有指定外部 workspace 與 task.md 的專案 | helper 的既有預設輸出不變；外部專案依模板直接寫正確位置，不執行預設 helper；安裝資源完整 |

評估結果及命令輸出保存在執行專案的規劃 workspace，不把私有證據複製進公開技能。涉及失敗注入的暫存操作只能證明檔案策略可行，不等同所有未來 agent 執行都會遵守規則。
