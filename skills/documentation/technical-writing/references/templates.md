# 文件骨架

## 架構文件

```markdown
# 系統名稱
## 目的與範圍
## 系統邊界與元件責任
## 主要資料流
## 關鍵取捨與限制
## 失敗模式、觀測與相關 ADR
```

## 操作手冊

```markdown
# 操作名稱
## 適用時機、影響與權限
## 前置檢查
## 程序
## 驗證與成功訊號
## Rollback 與故障排除
```

## ADR

```markdown
# ADR：決策名稱
## 狀態與日期
## Context
## Decision
## Alternatives
## Consequences
## 驗證與相關 ADR
```

骨架只提供起點；移除不服務讀者的段落，並補上該文件特有的風險與證據。
