# README 範例模式

## 一句價值主張

使用「`名稱` 是給 `讀者` 的 `類型`，用來 `完成任務`；相較於 `替代方式`，它 `可驗證差異`。」只在差異確有來源時寫出。

## 可驗證的快速開始

先說明版本前置條件，再將安裝、初始化、執行放在同一區塊，最後以網址、終端輸出或產物檔案標示成功訊號。不要使用未定義的 `foo`、`bar` 或省略必要環境變數。

## 漸進式使用範例

第一個案例只呈現常見工作；第二個加入設定；第三個才處理錯誤或進階情境。每個範例保留必要 import 與最小資料，複雜 API 改連到完整 reference。

## 文件連結

README 用一句話導向架構、部署、貢獻或 API 文件，並確保相對路徑與 heading 存在。不要複製整段專門文件回入口頁。
